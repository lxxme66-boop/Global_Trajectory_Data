┌─────────────────────────────────────────────────────────────────────┐
│ 📋 问题1: 输入需要哪些字段?                                         │
└─────────────────────────────────────────────────────────────────────┘

  输入文件: qa_data.jsonl (每行一个JSON对象)

  ┌──────────────┬──────┬──────────────────────────────────┐
  │ 字段         │ 必需 │ 说明                             │
  ├──────────────┼──────┼──────────────────────────────────┤
  │ question_id  │ ✅   │ 问题唯一标识 (用于去重/断点续传)│
  │ question     │ ✅   │ 用户问题 (推理的输入)            │
  │ answer       │ ❌   │ 标准答案 (可选,仅用于对比)       │
  └──────────────┴──────┴──────────────────────────────────┘

  示例:
  {"question_id": "qa_001", "question": "什么是OLED?", "answer": "..."}
  {"question_id": "qa_002", "question": "TFT原理?"}  ← answer可省略

  ⚠️  缺少question_id或question的条目会被自动跳过


┌─────────────────────────────────────────────────────────────────────┐
│ 🤖 问题2: 火山API vs vLLM - 谁更重要?                               │
└─────────────────────────────────────────────────────────────────────┘

  ╔═══════════════════════════════════════════════════════════════════╗
  ║                      vLLM (核心大脑) 🧠                            ║
  ╚═══════════════════════════════════════════════════════════════════╝

    作用: 所有推理决策的核心引擎
    端口: http://127.0.0.1:8000
    模型: Qwen3-32B (微调后)
    状态: ❌ 不能禁用 (禁用后脚本无法运行)

    调用场景:
    ┌─────────────────────────────────────────────────────────────┐
    │ 1️⃣  Judge阶段 (每一跳)                                      │
    │    输入: 问题 + 当前上下文                                   │
    │    输出: {knowledge_gap: true/false, query: "搜索查询"}     │
    │    作用: 判断是否需要更多信息                                │
    │                                                              │
    │ 2️⃣  Answer阶段 (最后)                                       │
    │    输入: 问题 + 所有累积上下文                               │
    │    输出: 完整答案                                            │
    │    作用: 基于检索到的知识生成最终回答                        │
    └─────────────────────────────────────────────────────────────┘

    典型调用次数: 3-6次/问题 (取决于多少跳)


  ╔═══════════════════════════════════════════════════════════════════╗
  ║                  火山引擎API (辅助翻译) 🌐                        ║
  ╚═══════════════════════════════════════════════════════════════════╝

    作用: 中英文翻译 + 语种检测 (提升RAG召回率)
    状态: ✅ 可以禁用 (禁用后降级为单语检索)

    调用场景:
    ┌─────────────────────────────────────────────────────────────┐
    │ 1️⃣  语种检测                                                │
    │    输入: "什么是OLED?"                                       │
    │    输出: "zh" (中文)                                         │
    │                                                              │
    │ 2️⃣  文本翻译                                                │
    │    输入: "什么是OLED?" + 目标语言"en"                        │
    │    输出: "What is OLED?"                                     │
    └─────────────────────────────────────────────────────────────┘

    典型调用次数: 4-10次/问题 (每跳2次: 检测+翻译)


  ╔═══════════════════════════════════════════════════════════════════╗
  ║                        重要性对比                                 ║
  ╚═══════════════════════════════════════════════════════════════════╝

    vLLM         ████████████████████████████████████  (100% 核心)
    火山API       ████████░░░░░░░░░░░░░░░░░░░░░░░░░░  (30% 辅助)

    结论: vLLM是大脑, 火山API只是锦上添花


┌─────────────────────────────────────────────────────────────────────┐
│ 🔄 完整数据流                                                        │
└─────────────────────────────────────────────────────────────────────┘

  输入: qa_data.jsonl
    ↓
  ┌──────────────────────────────────────────────┐
  │  Hop 1                                        │
  │  ┌───────────┐      ┌─────────────────┐     │
  │  │ vLLM判断  │ ───→ │ 需要更多信息     │     │
  │  └───────────┘      └─────────────────┘     │
  │         ↓                                     │
  │  ┌───────────┐      ┌─────────────────┐     │
  │  │ 火山翻译  │ ───→ │ 中文 → 英文      │     │
  │  └───────────┘      └─────────────────┘     │
  │         ↓                                     │
  │  ┌───────────┐      ┌─────────────────┐     │
  │  │ RAG检索   │ ───→ │ 返回知识块       │     │
  │  └───────────┘      └─────────────────┘     │
  └──────────────────────────────────────────────┘
    ↓ (累积上下文)
  ┌──────────────────────────────────────────────┐
  │  Hop 2 (重复上述流程)                         │
  └──────────────────────────────────────────────┘
    ↓
  ┌──────────────────────────────────────────────┐
  │  Hop N: vLLM判断 → 信息足够 (停止)           │
  └──────────────────────────────────────────────┘
    ↓
  ┌──────────────────────────────────────────────┐
  │  vLLM生成最终答案                             │
  └──────────────────────────────────────────────┘
    ↓
  输出: inference_trajectory.jsonl
