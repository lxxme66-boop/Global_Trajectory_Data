│                                                                  │
│  📄 轨迹质量筛选.py (24KB)                                       │
│                                                                  │
│  功能:                                                           │
│    1. 读取轨迹蒸馏的输出 (inference_trajectory.jsonl)          │
│    2. 调用vLLM进行9维度质量评估                                  │
│    3. 按质量分类输出 (high/medium/low)                          │
│    4. 生成筛选后的高质量数据 (filtered_trajectory.jsonl)       │
│                                                                  │
│  核心特性:                                                       │
│    ✓ 9个评估维度 (包含2个新维度)                                │
│    ✓ 自动化评估 (vLLM)                                          │
│    ✓ 并发处理 (支持多线程)                                      │
│    ✓ 详细评估报告                                               │
│    ✓ 改进建议生成                                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘


┌─ 新增评估维度 ─────────────────────────────────────────────────┐
│                                                                  │
│  ⭐ 维度6: 推理轨迹合理性 (Reasoning_Trajectory_Validity)      │
│                                                                  │
│    评估内容:                                                     │
│      • 每一跳的查询是否合理？                                   │
│      • 检索到的知识块是否相关？                                 │
│      • 推理过程是否呈现递进关系？                               │
│      • 是否存在无效检索或重复检索？                             │
│                                                                  │
│    示例:                                                         │
│      好: Hop1查OLED → Hop2查LCD → Hop3对比 ✅                   │
│      差: Hop1查OLED → Hop2又查OLED → Hop3偏题 ❌               │
│                                                                  │
│  ─────────────────────────────────────────────────────────────  │
│                                                                  │
│  ⭐ 维度7: 答案一致性 (Answer_Consistency)                      │
│                                                                  │
│    评估内容:                                                     │
│      • 答案是否与标准答案在核心观点上一致？                     │
│      • 是否存在重大技术偏差？                                   │
│      • 是否完整回答了问题的所有方面？                           │
│                                                                  │
│    示例:                                                         │
│      标准: "OLED是有机发光二极管"                               │
│      好: "OLED(有机发光二极管)使用有机材料..." ✅              │
│      差: "OLED是液晶技术..." ❌                                 │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘


┌─ 完整流程 (三步走) ────────────────────────────────────────────┐
│                                                                  │
│  步骤1: 轨迹蒸馏.py                                              │

│    输出: train_agent_data.jsonl (428条)                         │

✨ 核心优势
─────────────────────────────────────────────────────────────────

vs 手工筛选:
  • 速度: 100x 提升 (1000条/小时 vs 100条/天)
